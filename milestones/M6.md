# M6 — Session Recovery

## 目标

建立会话与异常恢复能力。

## 实现

- soft context threshold
- hard context threshold
- Session Archive
- New Session
- Project State 注入
- Memory 注入
- Recent Transcript 注入
- Browser Recovery
- Login Recovery
- checkpoint recovery

## Context 满处理

```
完成当前 turn
↓
保存 State
↓
摘要 Transcript
↓
新建 Session
↓
恢复任务
```

## 验收

以下情况后都可以继续任务：

```
Browser crash
WebSocket disconnect
Login expired
程序重启
Context 达到阈值
```
