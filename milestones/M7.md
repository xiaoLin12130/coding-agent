M5 单 Agent Loop 已稳定。

## 实现

```
Planner
Coder
Reviewer
MemoryCurator

```

以及：

```
AgentOrchestrator
```

## 协作原则

```
Planner
↓
Coder
↓
Reviewer
↓
修复？
├── 是 → Coder
└── 否 → 完成
```

辅助状态：

```
StateKeeper
MemoryCurator
SafetyGuard
```

## 强约束

不能：

- 绕过 Executor
- 直接写共享状态
- 无限循环
- 无限 Agent 对话

## 验收

简单 Coding Task 可以由多 Agent 协作完成。
