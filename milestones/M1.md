# M1 — Browser Driver

建立最小网页版 LLM 驱动能力。

## 实现

- Playwright
- headed browser
- persistent profile
- 页面打开
- 输入
- 发送
- 完成判定
- 回复抓取
- Screenshot
- DOM Snapshot
