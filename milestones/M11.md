# M11 — Console Chat Through the Real Model (streaming)

## 目标

在 Web UI 里提问 → 问题交给真实网页端模型 → 答案**流式**回传到 UI。

## 实现

```
UI 输入框（Ask model 模式）
↓  {"type":"ask","content":"..."}
WebSocket /ws
↓
AgentRuntime.ask()（工作线程）
↓
ModelClient.complete_stream() → BrowserModel
↓
WebChatProvider.ask_stream()（复用 wait_until_complete 的轮询）
↓  assistant_delta 事件（reset=false 增量 / reset=true 权威全文）
WebSocket → 前端 events.ts → 聊天气泡逐字增长
↓  done
```

要点：

- 与 agent run 完全分开：ask 不走工具、不走 Executor。
- `wait_until_complete` 负责完成判定，同时负责上报增量，**不重复实现**；
  早期版本另写了一个固定预算的循环，结果每个问题都要等满 180 秒。
- 后端订阅者（runtime）与 UI 的 delta 合流：前端 `assistant_delta` 累加，
  `reset=true` 时替换（最终以捕获到的文本为准）。

## 验证

- 离线：`tests/test_console_ask.py`（11 例）覆盖 runtime、REST、WS 帧与事件名。
- 真机：在 UI 里提问，DeepSeek 的回答流式出现在聊天区（`runs/` 内保留事件与截图）。
