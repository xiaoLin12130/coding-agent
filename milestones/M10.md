# M10 — Human-like Interaction and Session Reuse

## 背景

真实环境测试（打开网页端 DeepSeek）暴露的两个操作层面问题：

1. 脚本化的输入方式与真人差距太大：一次性 fill + 立即回车。
2. 每个问题都新开一个会话，与真人的使用习惯不符。

本里程碑只改"怎么操作页面"，不改 Agent 的执行链。

## 实现

### 拟人化操作

```
移动鼠标到输入框（分段移动，不是瞬移）
↓
点击输入框
↓
清空草稿（Ctrl+A / Backspace）
↓
逐字符输入，快慢混合
↓
停顿后回车
↓
回复完成后停顿
```

节奏要求：

- 快慢混合，不是单一均值：大部分字符走"快带"，少数走"慢带"；
- 停顿范围可配置，且每次随机；
- 词边界与标点额外停顿。

### 会话复用

```
第一个问题 → 新会话
第二个问题 → 同一会话（不重新导航、不新建对话）
```

`open()` 默认复用；只有显式 `new_conversation=True` 才开新会话。

### 默认开启深度思考

网页端的"深度思考"等开关由 profile 的 `toggles` 声明，发送前自动打开并校验
（未打开则点击，点击后仍未打开则报错）。

## 约束

仍然禁止：验证码绕过、指纹伪造、多账号规避、风控绕过。

拟人化只是**操作节奏**，不做任何浏览器伪装。

## 验收

- 单元测试：拟人化节奏（含 RNG 注入）、点击/清空/逐字符输入、开关默认开启、
  会话复用判定与 URL 记忆。
- 真机验证：对真实网页端模型连续提两个问题，第二个问题复用同一会话；
  深度思考开关处于打开状态。
