# M2 — State and Context

## 目标

建立 Context / State 基础。

## 实现

- TranscriptStore
- ProjectState
- MemoryStore
- ContextBuilder
- SessionManager 基础能力
- JSON / SQLite persistence

## Context

支持：

```
System
Task
Project State
Memory
Transcript
Tool Result
```

并支持：

- budget
- truncation
- summary

## Memory

只允许：

```
memory_propose
```

系统审核后写入。

## 验收

能够：

```
保存状态
→
关闭程序
→
重新启动
→
恢复状态
```

并正确构建 Context。
