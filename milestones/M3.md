# M3 — Tool System

## 目标

建立：

```
ToolCall
→
Parser
→
Executor
→
Tool Result
```

## Tool

至少：

```
list_dir
read_file
write_file
apply_patch
search
run_shell
memory_propose
update_project_state
ask_user
```

## Parser

支持：

- JSON
- JSON5
- Code Fence
- Multiple Tool Call
- 括号匹配

解析失败：

```
结构化错误
→
LLM 重试
→
最多 2~3 次
```

## Executor

支持：

- Schema Validation
- Logging
- Error Handling
- Idempotency
